# Глобальный план разработки

## Этап 1. Рабочий веб-MVP

- Авторизация через Supabase Auth.
- Роли: владелец, PM, офис менеджер, строитель.
- Таблица сотрудников с привязкой к Auth user.
- Проекты с адресом, контактами и описанием работ.
- Список техники.
- Дневные визиты по проектам.
- Назначение сотрудников и техники на визит.
- Проверка пересечений по времени.
- Статусы визита: запланирован, в процессе, завершен, отменен.
- Загрузка Safety Form при прибытии.
- Before photos для первого визита.
- Completion photos и описание выполненной работы.
- Office notes в отдельном поле.

## Этап 2. Документы, фото и поиск

- Private Supabase Storage buckets.
- Photo viewer.
- Аннотации на фото: карандаш, фигуры, текст.
- Сохранение оригинала и аннотированной копии.
- Загрузка PDF и Excel.
- Извлечение текста из PDF/Excel.
- Полнотекстовый поиск через Supabase.
- Иконки PDF/Excel в результатах поиска.

## Этап 3. Удобная работа PM

- Drag-and-drop расписание.
- Фильтры по проекту, дате, сотруднику и технике.
- Цветовые статусы визитов.
- Быстрое создание повторяющихся визитов.
- Уведомления о конфликтах.
- История изменений визита.
- Экспорт дневного отчета.

## Этап 4. PWA и мобильная готовность

- Installable PWA.
- Offline режим для открытых визитов.
- Очередь загрузки фото при плохом интернете.
- Camera-first flow для строителей.
- Push notifications.
- Capacitor wrapper для iOS и Android.

## Этап 5. Production hardening

- Audit log.
- Backups.
- Rate limits.
- Сжатие фото перед загрузкой.
- Тесты RLS политик.
- Separate staging и production Supabase проекты.
- Мониторинг ошибок.
